Telegram Channel & Group Permissions Architecture

Review bot permissions, group privacy mode boundaries, and future WhatsApp roadmap.

+
1. Private 1-on-1 Chats:

Direct chats with @CareerOrbitJobAssistantBot support all commands (/start, /help, /profile, /stats) and reply with structured confirmations for submitted opportunities.

2. Telegram Channels:

To capture announcements from a channel, the bot MUST be added as an Administrator with 'Post Messages' rights. Telegram only broadcasts channel_post events to admin bots.

3. Telegram Groups & Supergroups:

Telegram enables Privacy Mode by default. To capture job alerts without explicitly mentioning the bot, disable Privacy Mode in BotFather (/setprivacy -> Disable) or promote the bot to Admin.

4. Historical Messages & WhatsApp Roadmap:

The Telegram Bot API cannot retrieve messages sent prior to the bot joining. WhatsApp integration is isolated as a planned future channel using WhatsApp Web/Business Cloud APIs.
